# 第一周 程序设计与 C 语言

## 最简单的程序

```c
#include <stdio.h>

int main()
{
    printf("ZakoZako~\n");
    return 0;
}
```

逐行看：

- `#include <stdio.h>`：把头文件 stdio.h（standard input / output）包含进来；用到 `printf` / `scanf` 就必须写这一行（**预处理指令，末尾不加分号**）
- `int main()`：**主函数，程序从这里开始执行**，`int` 表示它返回一个整数
- `{ }`：函数体，里面放要执行的语句
- `printf("ZakoZako~\n");`：输出一行字，**语句结尾要加分号**
- `return 0;`：返回 0，表示程序正常结束

## 程序框架

```c
#include <stdio.h>

int main()
{
    return 0;
}
```

写新程序先敲好这个骨架，再往里填内容。

## 输出：printf

```c
printf("hello world!\n");
```

- `"hello world!\n"` 是字符串，用双引号包起来
- **`\n` 是转义字符，表示输出结果后要换行**；不写它，下一次输出会紧跟在这一行后面
- 反斜杠是 `\`，不要写成 `/`，也不要打成全角——`注意输入法`
- 语句结尾要加分号

### 占位符

```c
printf("%d", 2 + 2);                 // 4
printf("%d + %d = %d\n", 1, 2, 3);   // 1 + 2 = 3
```

- `%d` 先占一个位置，逗号后面的值**按顺序**填进这些位置
- **有几个 `%`，逗号后面就跟几个值，一一对应**
- `%d` 里也能写算式，C 会先算出结果再输出

### 常用转义字符

| 写法   | 含义                     |
| ------ | ------------------------ |
| `\n`   | 换行                     |
| `\t`   | 制表符（Tab，用来对齐）  |
| `\\`   | 一个反斜杠               |
| `\"`   | 双引号                   |
| `%%`   | 一个百分号               |

## 注释

```c
// 单行注释
/* 多行
   注释 */
```

注释是写给人看的，编译时会被忽略。

## 第一周容易出现的问题

- 分号、逗号、引号、括号打成**中文全角**（`；` `，` `“` `）`），编译报错
- `#include` 拼错，比如 `#incldue`
- 语句忘记加分号
- **`=` 和 `==` 混淆**（判断相等要用 `==`，后面周次会用到）
- 文件没存成 `.c` 后缀

# 第二周 变量与数据类型

## 变量

```c
int price;              // 定义变量 price
int price, amount;      // 定义变量 price 与 amount
int a = 1;              // 定义的同时给初值（初始化）
price = 10;             // = 是赋值符号，不是"相等"
price = price + 1;      // 先算右边，再把结果存回左边
```

- `int` 是类型，主要用来表示整数
- **变量要先定义再使用，赋过值再读**；没有初值的变量里是随机值
- 定义、赋值语句都以分号结尾

### 命名规则

- 只能用字母、数字、下划线，且**不能以数字开头**：`price_1` ✔，`1price` ✘
- **区分大小写**：`Price` 和 `price` 是两个不同的变量
- 不能用关键字：`int`、`return`、`if`、`while`…
- 命名约定（摘录）：常量全大写、多单词用下划线隔开；变量用下划线或驼峰，前后统一即可

## 数据类型

| 类型     | 说明         | 常见大小                   | 有效数字        | printf               | scanf            | 精度来自哪里                   |
| -------- | ------------ | -------------------------- | --------------- | -------------------- | ---------------- | ------------------------------ |
| `int`    | 整数         | 4 字节（32 位），约 ±21 亿 | 精确，无误差    | `%d`                 | `%d`             | 直接存整数值，能表示就一定精确 |
| `float`  | 单精度浮点数 | 4 字节                     | 约 **6~7 位**   | `%f`                 | `%f`             | 有效数字占 24 个二进制位       |
| `double` | 双精度浮点数 | 8 字节                     | 约 **15~17 位** | `%f`（`%lf` 也可以） | `%lf`（**必须**） | 有效数字占 53 个二进制位       |

==C 里看的是有效数字位数（从第一个非零数字算起），不是固定的小数位数。==

**「有效数字」不是「小数点后的位数」**：有效数字从第一个非零数字开始数，前导的 0 不算。同一个 `double`，小数点后能信几位完全看数值多大：

- `10.0` 是浮点数（double），`10` 是整数（int）：**既然类型不同，在 C 语言中就是两个不同的值**
- **浮点数有误差**：`0.1 + 0.2` 不一定正好等于 `0.3`，比较两个浮点数要看差值是否足够小

## 常量 const

```c
const int AMOUNT = 100;   // 定义时必须初始化
AMOUNT = 90;              // error：const 变量不能再被赋值
```

- **`const` 变量被初始化后无法修改**
- 命名约定（摘录）：常量全大写、多单词用下划线隔开
- 另一种常量写法（预处理指令，不带类型、末尾不加分号）：

```c
#define AMOUNT 100
```

## 输入：scanf

```c
int a, b;
scanf("%d %d", &a, &b);
```

- **`&` 取地址符不能省略**：它告诉 scanf 把读到的值存到哪个变量里（数组名本身是地址，那种情况不加，之后再学）
- **格式串里写什么，输入时就要照着敲**：
  - `scanf("%d %d", &a, &b)` → 输入 `1 2`
  - `scanf("%d,%d", &a, &b)` → 输入 `1,2`
- **格式串里不要加 `\n`**
- `%d` 会自动跳过前面的空格和换行，所以输入 `   1    2` 也能读对；**`%c` 不跳过，会读到空格或回车**
- 格式符要和变量类型对上，用 `%d` 读 `double` 会得到完全错误的值
- `scanf` 的返回值是"成功读入了几项"，可以用它判断输入是否有效

## 格式符对照

| 类型     | printf 输出             | scanf 输入   |
| -------- | ---------------------- | ------------ |
| `int`    | `%d`                   | `%d`         |
| `float`  | `%f`                   | `%f`         |
| `double` | `%f`（写 `%lf` 也可以）  | `%lf`（必须） |

- `%f` 用来表示浮点数，也就是小数
- 后面学到的 `%c`（字符）、`%s`（字符串）同理，**也要和变量类型一一对上**

## 控制输出格式

```c
printf("%.3f\n", 3.14159);    // 3.142，保留小数点后三位
printf("%.2f\n", 3.14159);    // 3.14
printf("%5.2f\n", 3.14159);   // " 3.14"，总宽 5 位，不足处补空格
```

- **`%.3f` 只用在 printf 里**，表示输出时保留几位小数
- `scanf("%.3f", &x)` 是**非法格式**，读入直接用 `%f` / `%lf`

# 运算符与表达式

## 四则运算与取余

```c
5 / 2        // 2，不是 2.5：两边都是整数，结果就是整数（向零截断）
5.0 / 2      // 2.5：只要有一边是浮点数，就按浮点算
7 % 3        // 1，百分号用作取余
5 % 2        // 1
```

- **想让除法得到小数，至少把一边写成浮点数**：`5.0 / 2`、`(double)5 / 2`
- `%` 两侧都必须是整数，`7.0 % 3` 编译就过不去；`%` 结果的符号跟左边的数一致（`-7 % 3` 是 `-1`）
- **除数不能为 0**：`5 / 0`、`5 % 0` 都会让程序崩掉
- 别和 `%d`、`%f` 里的百分号搞混：那是格式占位符，不是运算

## 类型转换

```c
(int)3.7        // 3，直接截掉小数部分，不是四舍五入
(double)5 / 2   // 2.5
```

- 两种类型一起运算时，范围小的先转成范围大的（int → double）
- `(类型)值` 是强制转换，要写清楚意图，**别指望它帮你四舍五入**

## 优先级与结合方向

从高到低：

1. 括号 `( )`
2. 单目运算符：取负 `-`、正号 `+`、`++`、`--`
3. 乘、除、求余 `*` `/` `%`
4. 加、减 `+` `-`
5. 赋值 `=`（以及 `+=` 这类复合赋值）

- 同一优先级从左往右算；**赋值从右往左**：`a = b = c;` 是先把 `c` 赋给 `b`，再把 `b` 赋给 `a`
- **单目运算符优先级最高，赋值最低**
- 记不住就加括号，括号永远最省事

## 复合赋值

```c
total += (sum + 100) / 2;   // 等价于 total = total + (sum + 100) / 2;
total *= sum + 12;          // 等价于 total = total * (sum + 12);
```

- `+=` `-=` `*=` `/=` `%=` 都是"先算右边，再和左边运算，结果存回左边"
- **右边整个表达式算完才参与运算**：`total *= sum + 12` 不是 `total * sum + 12`

## 递增递减 ++ --

```c
int a = 5;
int b = a++;   // ++ 在后：先使用，b 得到 5，然后 a 变成 6
int c = ++a;   // ++ 在前：先加 1，a 变成 7，然后 c 得到 7
```

- `count++` 表示为 `count += 1`，也就是 `count = count + 1`
- **`++` 在后：先使用再 +1；`++` 在前：先 +1 再使用**

```c
int a = 7 ;
b = a++ ;
```

则 b=7 a=8，`++` 则反

- 单独写一行时，`a++;` 和 `++a;` 效果一样；**只有嵌在表达式里才有区别**

## 嵌入式赋值（不要写）

==🔴不要去做嵌入式赋值！！！== 下面这种写法能编译，但可读性差、容易算错：

```c
int a = 6;
int b;
int c = 2 + (b = a);   // 不推荐：把赋值塞进表达式里
```

## 交换两个变量的值

说白了就是引入一个新的变量 c 当中转：

```c
int a = 1, b = 2;
int c;

c = a;   // 先把 a 存进 c，免得被覆盖
a = b;   // a 变成 2
b = c;   // b 变回原来 a 的值，即 1
```

**顺序不能反**：如果先写 `a = b;`，`a` 原来的值就丢了。

## 进制换算

- 18 的十进制表达 `10010`
- 18 的十六进制表达：`0x12`
- 将 18 十六进制化：`18/16 18%16`商与余的拼接

## 调试与断点检查

==原文标注"这个部分后续进行补完"，上面是先记下的要点，上完课再补具体操作==

结果不对时别靠猜，用断点看变量是在哪一步变掉的：

- 在代码行号左边点一下可以下一个**断点**，程序运行到这一行就会停下来
- 停下来以后可以查看每个变量当前的值，也可以单步执行（一行一行往下走）
- 常见用法：在循环里下断点，**观察计数器、累加变量每一步的变化**

# 第三周 判断与分支

## 关系运算符

- **`==` 用作判断是否相等**
- **`!=` 判断是否不相等**

- 连续的大于小于运算从左往右算

```text
算术运算（+ - * / %）> 关系运算 > 相等性运算（== !=）> 逻辑运算（&& ||）> 赋值（=）
其中关系运算内部：< <= > >= 高于 == !=
```

```c
    巴拉巴拉;

```

- `if` 后面的（ ）语句成立，则执行 `{ }` 中的内容
- **不成立 则直接绕过**
- **if 后面不直接加 ；**
- 在大括号内的语句加

## else

- **else 总是与他最近的 if 匹配**
- ==🔴但是 {   }的优先级更高，换而言之就是 {  } 可以使上面这条规则弱化，所以！！**一定要用大括号！**==

## 多路分支：switch-case

将多个 if-else 级联语句直接简化

```c
switch(type)
{
 case 1:
  printf("你好");
  break;
 case 2:
  printf("Good morning");
  break;
 case 3:
  printf("Good afternoon");
  break;
 default:
   printf("What?");
}
```

- 其中 type 需要 int 类型的数字
- `const int` 可行
- **`break` 在循环中相当于 `return 0`**，==🔴即可以跳出循环==
- switch-case 只不过是一个跳跃式的 if else
- **假如我输入的是 2 则是从 case2 一直往下推，而不是做完 case2 就直接停止**
- switch-case 能做的 if-else 都能做，反之不然

# 第六周 数据类型

## 类型总览

C 语言要在使用前进行定义并确定类型

类型：

- 整数 char, short, int, long, long long
- 所用内存从小到大

浮点数在内部以编码形式存储，运算会带精度误差，在计算机内部它们以编码的形式储存

## 函数

```c
sizeof(a)
```

可以显示 a 在计算机内部占有的字符数

```c
printf("%ld",sizeof(int))//此函数可以用来求int的字符数
```

sizeof 为静态运算符

eg:

```c
a=7;
sizeof(a++)
```

此处 a 的输出仍然为 7

但是

如果为

```c
printf("%ld",sizeof(a+1.0))
```

此处占有的字符数类型为 double 整数类型所占有的字符数，而非 int 类型的

## 补码与无符号数

在计算机中 通过==🔴补码==来表示负数

0 开头为正数 而 1 开头为负数

以 char 这一类型的整数为例占用八个 bit 一个字节

一共可以表 $2^8$ 个数字（共计 256 个）

从 -128 至 127，其中 0 占据了 00000000，故而正数的数字比负数少一个

如果储存的数字超过 127 则会溢出变成 1000-0000，显示为 -128，-1 为 1111-1111

```c
unsigned char
```

这一函数可以使所有位都拿来存数，没有符号位

此时则有 0 到 255

255 为最后一位数 1111-1111，256 应为 0001-0000-0000，但是由于 char 字符只能保留 8 位比特，因此溢出，回归为 0

## 整数的输入输出

只有两种形式  int 或 long long

- `%d`：int
- `%u`：unsigned
- `%ld`：long long
- `%lu`：unsigned long long

`%o` 用于八进制，`%x` 用于十六进制

一个以 0 开始的数字字面量为八进制

一个以 0x 开始的数字字面量为 16 进制

8 进制与 16 进制只是如何把数字表达为字符串，与内部如何表达数字无关

一个好玩的东西

```text
0001-0010
```

其中 0001 为 1，0010 为 2

因此比较好实现 16 进制与 2 进制的转换

普遍用 int 能满足当下 99% 的情况

## 浮点类型

- float 所占用内存 32bit 有效数字为 7 位 采用 "%f"
- double 所用内存 64bit 有效数字为 15 采用 "%lf"
- 此处的有效数字不是数学定义，而是表明它的精度在有效数字后降低
- 1E-10 为一的负十六次方
- 在计算机中 inf 用来表示无穷大的数字，而 nan 则为不存在的数字
- 无穷大无法用整数表达,==🔴但是在浮点数中可以被表达==
- ==🟡带小数点的字面量其实是 double 而非 float，float 需要用后缀 f 来表明身份==

因此，浮点数的“`==` ”可能会失败

可用==🔴fabs（f1 -f2）<le-12==进行判断

le-12 不一定，只需要小于浮点数的精度就行

浮点数内部用编码进行实现，而不是二进制数

可以用单引号来表示字符字面量 如 char c =‘1’

但是 i=49 时候

前一个输出会是 49，后一个输出为‘1’

## 指针

就是保存地址的变量

## 指针作为函数参数

```c
void f(int *p);      // 形参是一个指针
int i = 0;
f(&i);               // 调用时把 i 的地址传进去
```

在被调用的时候得到了某个变量的地址

在函数里面可以通过这个指针访问外面的这个 i

也就是说 函数拿到了 i 的地址 就能顺着地址去改 i 本身

这就是"函数改不动外面的变量"那个问题的解法 —— 传地址,不传值

```c
void f(int *p)
{
    *p = 100;        // 顺着 p 里的地址回去,改的就是外面的 i
}

int main()
{
    int i = 0;
    f(&i);
    printf("%d\n", i);   // 100
    return 0;
}
```

对比

```c
void f(int x)  { x = 100; }    // 传值:改的是副本,外面的 i 还是 0
void f(int *p) { *p = 100; }   // 传地址:顺着地址改,外面的 i 变成 100
```

==🔴值传递改不动外面,要改外面的变量就传它的地址==

## 用指针改结构：两种情况

# 全局变量与静态本地变量

## 全局变量

全局变量

意思就是你无论函数在哪 你只要在函数外面定义了一个变量 就能在全局都使用

在函数里面对全局变量进行更改 它自己本身就会被修改 没副本这一说

只定义 不初始化默认为 0

如果是指针 那指针就是 NULL 了

```c
#include <stdio.h>

int f(void);

int gAll=12;

int main(int argc, char const *argv[])
{
    printf("in %s gAll=%d\n", __func__, gAll);
    f();
    printf("agn in %s gAll=%d\n", __func__, gAll);
    return 0;
}

int f(void)
{
    int gAll = 1;
    printf("in %s gAll=%d\n", __func__, gAll);
    gAll += 2;
    printf("agn in %s gAll=%d\n", __func__, gAll);
    return gAll;
}
```

输出：

```text
in main gAll=12
in f gAll=1
agn in f gAll=3
agn in main gAll=12
```

内部的同名变量会暂时覆盖 而非替换

## 静态本地变量

```c
static int all=1;
```

出了函数的那个生存期之后 不会被释放

```c
#include <stdio.h>

int f(void);

int gAll=12;

int main(int argc, char const *argv[])
{
    f();
    f();
    f();
    return 0;
}

int f(void)
{
    static int all = 1;
    printf("in %s all=%d\n", __func__, all);
    all += 2;
    printf("agn in %s all=%d\n", __func__, all);
    return all;
}
```

输出：

```text
in f all=1
agn in f all=3
in f all=3
agn in f all=5
in f all=5
agn in f all=7
```

其实本质是全局变量（）

所以上一次对静态本地变量的修改会延续到下一次的调用

```c
#include <stdio.h>

int f(void);

int gAll=12;

int main(int argc, char const *argv[])
{
    f();
    return 0;
}

int f(void)
{
    int k=0;
    static int all = 1;
    printf("&gAll=%p\n", &gAll);
    printf("&all =%p\n", &all);
    printf("&k   =%p\n", &k);
    printf("in %s all=%d\n", __func__, all);
    all += 2;
    printf("agn in %s all=%d\n", __func__, all);
    return all;
}
```

输出：

```text
&gAll=0x3800c
&all =0x38010
&k   =0xbffc9d4c
in f all=1
agn in f all=3
```

`&all` 紧挨着 `&gAll`（0x3800c → 0x38010），离栈上的 `&k` 很远 —— 此处是静态本地变量是全局变量的证明

## 返回指针的函数

返回指针的函数

- 返回本地变量的地址是危险的
- 返回全局变量或静态本地变量的地址是安全的
- 返回在函数内 malloc 的内存是安全的，但是容易造成问题
- 最好的做法是返回传入的指针

| 名字 | 定义 | 例子 |
| --- | --- | --- |
| **野指针** wild | 从来没被赋值过，指向随机地址 | `int *q; *q = 1;` |
| **悬空指针** dangling | 曾经合法指向过某对象，该对象已死 | `int *p = f();`（f 返回了局部变量地址） |
| **空指针** NULL | 明确不指向任何东西 | `int *p = NULL;` |

全局变量不好的地方——差不多就是其实一直占用内存

```c
#include <stdio.h>

int* f(void);
void g(void);

int main(void)
{
    int *p = f();

    printf("*p=%d\n", *p);   /* 期望 12（残影） */
    g();
    printf("*p=%d\n", *p);   /* 期望 24（槽被 k 占了） */

    return 0;
}

int* f(void)
{
    int i = 12;
    return &i;               /* 警告：返回局部变量的地址 */
}

void g(void)
{
    int k = 24;
    printf("k=%d\n", k);
}
```

实际上就是即使你这个变量（i）所处的生命期到了 但是它这个地址在下一个函数的生命期里被复用了 就导致了你读指针所指的地址里面的变量 你读到的是一个新的变量（k）

AI 标准版话语：变量 `i` 的生命周期结束时，它占用的**地址空间并没有消失**，只是那块内存不再属于任何变量。下一个同深度的函数调用会把局部变量放进同一个槽位，于是 `k` 的 24 就写在了 `*p` 指向的地方。读 `*p` 得到的不是"变量 k"，而是"k 写在那块无主内存里的字节"

- `<>` 让编译器只在指定的目录去找

- `#include <stdio.h>` 只是为了让编译器知道 printf 函数的原型，保证你调用时给出的参数值是正确的类型

- 在函数前面加上 static 就使得它成为只能在所在的编译单元中被使用的函数
- 在全局变量前面加上 static 就使得它成为只能在所在的编译单元中被使用的全局变量

- `int i;` 是变量的定义
- `extern int i;` 是变量的声明

二进制读写：

```text
size_t fread(void *restrict ptr, size_t size, size_t nitems, FILE *restrict stream);
size_t fwrite(const void *restrict ptr, size_t size, size_t nitems, FILE *restrict stream);
```

- 注意 FILE 指针是最后一个参数
- 返回的是成功读写的字节数

```text
long ftell(FILE *stream);
int fseek(FILE *stream, long offset, int whence);
```

- SEEK_SET：从头开始
- SEEK_CUR：从当前位置开始
- SEEK_END：从尾开始（倒过来）

可移植性：

- 这样的二进制文件不具有可移植性
  - 在 int 为 32 位的机器上写成的数据文件无法直接在 int 为 64 位的机器上正确读出
- 解决方案之一是放弃使用 int，而是 typedef 具有明确大小的类型
- 更好的方案是用文本
